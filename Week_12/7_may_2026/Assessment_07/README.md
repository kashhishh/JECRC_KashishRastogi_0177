# Product Price Analyzer

## 📌 Project Overview

Product Price Analyzer is a C# console application designed to analyze retail product prices using array operations and searching/sorting algorithms.

The system performs:

- Custom sorting
- Binary search
- Pair sum analysis
- Longest increasing subsequence detection
- Statistical calculations

This project demonstrates important concepts of:

- Arrays
- Sorting Algorithms
- Searching Algorithms
- HashSet
- Data Analysis

---

# 🚀 Features

✅ Store product prices in arrays

✅ Implement Bubble Sort

✅ Perform Binary Search

✅ Find pairs with target sum

✅ Detect longest increasing subsequence

✅ Calculate statistics
