# Sales Data Aggregator

## 📌 Project Overview

Sales Data Aggregator is a C# console application used to analyze product sales across multiple regions.

The system performs advanced sales analysis including:

- Product-wise sales grouping
- Region-wise aggregation
- Total and average sales calculation
- Best-selling product detection
- Underperforming product identification

This project demonstrates the use of:

- LINQ GroupBy
- Aggregation Functions
- Collections
- Data Analysis
- Business Reporting

---

# 🚀 Features

✅ Group sales by product

✅ Group sales by region

✅ Calculate total sales

✅ Calculate average sales

✅ Find minimum and maximum sales

✅ Detect best-selling products

✅ Identify underperforming products

# 🛠 Technologies Used

- C#
- .NET Console Application
- LINQ

- GroupBy
