# Word Frequency Analyzer

## 📌 Project Overview

Word Frequency Analyzer is a C# console application that analyzes a paragraph of text and performs word frequency analysis.

The application:

- Counts total words
- Counts unique words
- Finds most frequent words
- Detects words appearing exactly once
- Ignores punctuation
- Performs case-insensitive analysis

This project demonstrates the use of:

- Dictionary
- String Manipulation
- Regular Expressions (Regex)
- LINQ
- Text Processing

---

# 🚀 Features

✅ Read and analyze paragraph text

✅ Convert text to lowercase for case-insensitive comparison

✅ Remove punctuation automatically

✅ Count frequency of every word

✅ Display top N frequent words

✅ Find words appearing exactly once

✅ Calculate average word frequency
