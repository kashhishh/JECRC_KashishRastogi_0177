# Student Grade Processor

## 📌 Project Overview

Student Grade Processor is a C# console application used to analyze and process student grades across multiple subjects.

The system performs various analytical operations such as:

- Average grade calculation
- Highest and lowest grade detection
- Top performer identification
- Student filtering based on grade threshold
- Unique grade analysis

This project demonstrates the use of:

- Arrays
- Dictionary
- HashSet
- LINQ
- Data Processing Techniques

---

# 🚀 Features

✅ Store grades for multiple students

✅ Calculate average marks

✅ Find highest and lowest grades

✅ Identify top performer

✅ Detect students with all grades above threshold

✅ Count unique grade values

✅ Sort and display unique grades
