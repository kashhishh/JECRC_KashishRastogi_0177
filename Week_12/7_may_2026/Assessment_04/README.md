# Sequence Pattern Detector

## 📌 Project Overview

Sequence Pattern Detector is a C# console application designed to analyze access logs and detect important numerical patterns.

The application performs multiple analytical operations such as:

- Longest consecutive sequence detection
- Frequency analysis
- First non-repeating element detection
- Pair finding with difference K
- Majority element detection

This project demonstrates efficient use of:

- Arrays
- Dictionary
- HashSet
- LINQ
- Pattern Detection Algorithms

---

# 🚀 Features

✅ Find longest consecutive sequence

✅ Find most frequent element

✅ Detect first non-repeating element

✅ Find pairs with difference K

✅ Detect majority element

✅ Efficient searching using HashSet
